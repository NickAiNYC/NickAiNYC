## The Thesis

> **Agent logic should not be trapped inside one framework, SDK, prompt chain, or vendor runtime.**

I build **standards-shaped AI infrastructure**: portable agent workflows, verifiable execution traces, adapter ecosystems, and governed systems that can be inspected when something breaks.

```text
Write once. Run anywhere. Inspect everything. Replay anything.
```

---

## The Work: INFINI

**INFINI is the standard layer for portable autonomous work.**

It turns autonomous work into a portable Loopfile: define the loop once, execute it through different runtimes, verify the result, and replay the trace when the system needs to be debugged.

<table>
  <tr>
    <td width="55%" valign="top">
      <h3>What INFINI Standardizes</h3>
      <ul>
        <li><strong>Loopfiles</strong> — declarative YAML for agents, steps, budgets, verification, and stop conditions</li>
        <li><strong>Adapters</strong> — a clean bridge between the spec and execution engines: Hermes, OpenClaw, LangGraph, CrewAI</li>
        <li><strong>Traces</strong> — structured records of what happened, what changed, and why</li>
        <li><strong>Replay</strong> — inspect failures at the loop level, not only the log level</li>
        <li><strong>Observatory</strong> — a visual layer for runs, steps, verification, and agent behavior</li>

## The Loopfile Pattern

```yaml
LOOPFILE: "1.0"
name: research-assistant

AGENTS:
  - { name: researcher, role: builder, model_tier: sonnet }
  - { name: verifier,  role: critic, model_tier: haiku }

STEPS:
  - { id: s1, name: find-sources, action: run, uses: browser, agent: researcher }
  - { id: s2, name: verify, action: run, uses: verify_citations, agent: verifier, depends_on: [s1] }

VERIFY:
  syntactic: ["every_claim_has_citation"]
  semantic: ["source_quality >= 85"]
  confidence_threshold: 85

BUDGET:
  dollars: 6.00
  minutes: 20

STOP_WHEN:
  - SUCCESS
```

<div align="center">

```text
Loopfile → Validation → Engine → Adapter → Execution → Trace → Replay → Observatory
```

## Engineering Principles

```text
Spec first.
Readable artifacts over opaque magic.
Every loop needs a verifier.
Every verifier needs a trace.
Every trace should be replayable.
Zero infrastructure is a feature.
```

I build systems that are understandable under pressure: when a demo fails, when an agent drifts, when a customer asks why, when a regulator asks for proof, or when a contributor wants to extend the standard.

## The Mission

I'm building the standard layer for autonomous work — infrastructure that makes AI agents portable, inspectable, and governable.

| Principle | What It Means |
|---|---|
| **Portable** | Write agent logic once. Run it through any engine. |
| **Inspectable** | Every run produces a trace. Every trace can be replayed. |
| **Verifiable** | Every loop has verification. Every verification has confidence. |
| **Governable** | Budgets, stop conditions, policies, and audit trails. |
| **Open** | Specs, schemas, adapters, and registries anyone can extend. |
